### 🚀 Getting Started Locally

To run any module locally, navigate to its directory, install the dependencies, and start the development server:

```bash
# Navigate to a project folder (e.g., 11-ecommerce-project)
cd 01-course-practice/11-ecommerce-project

# Install dependencies
npm install

# Start the development server
npm run dev
```

> **Note:** To run `16-firebase`, create a `.env` file in the `01-course-practice/16-firebase` directory and add your own `VITE_FIREBASE_*` configuration keys.
